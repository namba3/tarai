# Tak (Tarai) Function

[日本語](README.md) | [English](README.en.md)

This repository implements the Tak (Tarai) function in four ways:

- Naive recursion
- Memoized recursion
- Lazy evaluation using closures
- Lazy evaluation using an enum

## Benchmark

The benchmarks run on stable Rust.

```sh
cargo bench
```
